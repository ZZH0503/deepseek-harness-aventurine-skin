# DeepSeek Harness 砂金·戏浪皮肤插件

（dsh-aventurine-skin）—— 《崩坏：星穹铁道》「砂金·戏浪」（Aventurine • Waveflair）主题。

深海青蓝 × 金色筹码的终端整体换肤：多层景深、沉浸式双立绘、砂金桌宠、任务完成台词气泡、开屏动画。

## 功能

- **整体主题皮肤**：依据官方立绘与 PV 演出实际取色，深海洋底 / 浅青假日两套完整 `--dsw-*` token，界面统一换肤；侧边栏激活项金色胶囊高亮、聊天气泡金边毛玻璃、输入框深海玻璃质感；
- **多层景深**：左右两张人物立绘（径向羽化 alpha 已烘焙进 PNG，无矩形边框）沉入终端两侧 + 中部光桥 + 波纹纹理 + 弥散光 + 边缘微光 + 筹码/气泡粒子画布 + 鼠标视差——是画面层次而非贴纸；
- **砂金桌宠**：圆形头像 + 金环 + 环绕筹码，可拖动；任务开始弹「处理中」随机台词，任务结束弹「任务完成！+ 随机官方台词」（玻璃悬浮气泡，透视倾斜+毛玻璃+漂浮），点击桌宠也可对话；
- **开屏动画**：每次打开终端全屏播放角色 PV《独家爆料》26-32 秒精选片段（已去水印、1440p 高清重制），即时黑幕盖屏（绝无终端先闪现）→ 首帧交叉淡入 → 结尾声音渐弱+画面渐暗+镜头回稳 → 丝滑落回终端；
- **稳定性**：全部外部调用 try/catch、启动初始化整体保护（任何异常不拖垮应用）、与 `dsh-usage-cost-meter` 等插件兼容共存、资源带版本参数防缓存；
- **设置面板**（设置 → 通用）：总开关、开屏动画/粒子/背景/桌宠独立开关、深浅配色、立绘大小/亮度、桌宠大小与重置、音量、试播开屏动画。

## 任务完成台词

台词文本来自米游社角色百科「砂金·戏浪」官方语音页（中文配音：杨超然）与米哈游官方视频中文字幕，共 18 条，随机展示。纯文字气泡方案（不播放音频）。

## 安装

```sh
dsh plugin --profile desktop add -w ./dsh-aventurine-skin
```

安装后**完全退出并重新打开**终端（Ctrl+R 可能被拦截）。设置入口：设置 → 通用 → 砂金·戏浪皮肤。

## 结构

- `lib/index.js` —— 宿主半：`/aventurine-skin/*` 静态素材路由（同源校验、文件名清洗、Range 支持）+ 任务状态桥（`agent/status`、`session/event` 事件 → `/aventurine-skin/status`）；
- `lib/client.js` —— 浏览器半：主题、景深、桌宠、台词、开屏动画、任务监测、设置面板；
- `assets/img|video|voice.json` —— 处理后的素材（原始下载件不入库）；
- `cordis.patch.yml` —— 单 loader 条目（宿主/浏览器共用，禁止拆分双条目）。
